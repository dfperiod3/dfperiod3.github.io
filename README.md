# Perilous Frontiers Pledge Optimizer

Live at https://dfperiod3.github.io/

Enter the pieces you want and the optimizer finds the cheapest combination of
[Perilous Frontiers](https://gamefound.com/en/projects/dwarven-forge/perilous-frontiers/rewards)
sets and bundles that contains at least those pieces. It is an integer linear program,
solved in your browser by [HiGHS](https://highs.dev) (via
[highs-js](https://github.com/lovasoa/highs-js)). Most solves take well under a second,
including "one of every painted piece".

## Using it

- **Desired pieces (left).** Type a quantity next to any piece. The shortcut buttons set
  every painted (`-P`) or unpainted (`-U`) piece to at least 1. Pegs, rods, textures and
  other accessories are listed too and default to 0. Your entries are remembered in your
  browser. **Save** and **Load** move them in and out as a CSV file.
- **Sets & bundles (right).** **Add** puts a set's contents into your desired pieces and
  **Sub** takes them out. In **Max** mode, Add raises each piece to at least the set's
  quantity instead of adding to it. Use that to ask for "enough to build A *or* B, but
  not both at once": Add A, then Add B. **Omit** stops the optimizer from choosing a set
  (for example, to see how a bundle breaks down into individual sets). Click a set's
  name to see its contents.
- **Optimize (bottom).** The **Pledge summary** lists the chosen sets and, for each one,
  which desired pieces you'd lose with one fewer copy. The **Item manifest** shows
  everything in the pledge, and can be filtered to just the extras you didn't ask for.
- **Prices.** Gamefound campaign prices; bundles use their discounted bundle price.
  Shipping and tax are not included.
- **Theme.** Pick Desert or Arctic colors from the dropdown at the top. Both follow your
  system's light/dark setting.
- **Tolerance / time limit.** If a solve is ever slow, a tolerance of e.g. 5 accepts any
  pledge within 5% of the cheapest. When the time limit is reached, you get the best
  pledge found so far.

The **Help** button (top right) opens the full in-page guide, including recipes for
common questions. Hover over (or tap) any button, column heading or **?** badge for
quick help.

## Updating the data

Set compositions and prices come from the community spreadsheet
(https://docs.google.com/spreadsheets/d/19gbXlWYlA12Q_4Mj2LTzqhgbcyVtuQR0fl3VCSm91sg).
These tabs are used: *Pieces*, *Sets by Category*, *Set Comps* and *Bundle Builder*. To
refresh after the sheet changes:

```sh
pip install openpyxl
python3 tools/build_data.py            # downloads the sheet and rewrites data.json
git commit -am "Update set data" && git push
```

Sets without a price (currently the treasure chests) are skipped and listed in the
script's output.

## Files

| File | Purpose |
| --- | --- |
| `index.html`, `style.css` | Page layout |
| `app.js` | UI: piece and set lists, save/load, results |
| `optimizer.js` | Builds the LP model and reads the solution (shared with the tests) |
| `data.json` | Generated by `tools/build_data.py`; do not edit by hand |
| `tools/test_optimizer.js` | Solver sanity checks: `npm install highs@1.15.3 && node tools/test_optimizer.js` |

Everything is static, so GitHub Pages serves it as-is. To try it locally, run
`python3 -m http.server` in the repository root and open http://localhost:8000. Opening
`index.html` directly won't work, because browsers block `fetch` of local files.
